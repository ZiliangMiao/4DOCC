> 范围: 推导, 算法, 复杂度与显存, 与论文 / 原代码的差异, 风险与待确认事项.

## 0. 结论摘要

| 问题 | 结论 |
|---|---|
| 1. label 计算能否统一, 不按夹角分情况 | **有条件地能.** 在 "线束 = 发散锥, 重叠 = 轴线距离不超过两处半径之和" 的模型下, 重叠深度集合是当前束上的**单个区间**, 由一个二次不等式闭式求出. 它同时覆盖大夹角 (短区间), 小夹角 (长区间或无界区间), 原点重合, 严格平行, 异面, 不需要共面判定. 条件: (a) 接受 "半径之和" 这一近似 (论文 Eq. 14 已在用); (b) 无界区间必须用有限上界截断 (测距上限, 以及 w_conf 下限对应的相邻束深度上限); (c) 需要确定一个论文中存在歧义的系数 κ (见 2.5.3). |
| 2. 能否 GPU 并行加速 | **能.** 关键不在 GPU 本身, 而在去掉 N×M 稠密计算: 本文证明了一个**无漏检**的候选剪枝 (过基线的平面束 + 一维方位角索引), 每对帧的复杂度从 O(NM) 降为 O((N+M) log M + K), 合成数据上 K ≈ 0.87% NM. 实现是纯 PyTorch 的逐元素运算, 分块后显存有界, CPU / GPU 结果一致. |

实测 (本容器 CPU, 4 线程, 合成 nuScenes 规模数据, 每帧 34560 点, 12 个相邻帧): 每个当前帧 25.7 s; 同一份代码在 5760 点规模上, 剪枝比稠密快约 97 倍 (0.41 s vs 39.5 s), 输出逐位相同. GPU 估算见 3.5.

需要用户确认的事项见第 6 节, 其中 κ 的取值与输出样本量两项会实质影响结果.

## 1. 记号与对现有实现的核实

### 1.1 记号

- 全部在当前帧 t0 坐标系中计算, 并把当前传感器原点平移到 0. 相邻帧传感器原点记为 a (即论文中的 a^t 相对 a^{t0}).
- 当前束 i: 单位方向 d_i, 命中距离 r_i. 相邻束 j: 原点 a, 单位方向 d_j, 命中距离 r_j.
- c = d_i · d_j = cos α, m = d_i × d_j, |m|² = sin² α.
- u = d_i · a, v = d_j · a, |a × d_j|² = |a|² − v² (当前原点到相邻束轴线距离的平方).
- τ = tan(θ_dvg / 2), 锥在轴向深度 s 处的半径为 τ s.
- 当前束上深度 s 的点 x(s) = s d_i. 它在相邻束轴线上的垂足参数 t(s) = (x(s) − a) · d_j = c s − v.

## 2. 问题 1: 统一判据

### 2.1 模型

每条线束是顶点在传感器原点, 轴为 d, 半角 θ_dvg / 2 的圆锥. 当前束上深度 s 处的点 x(s) 称为与相邻束 j **重叠**, 当且仅当

```
κ · dist(x(s), 轴线 j)  ≤  R(s) = τ s + τ t(s),          t(s) = c s − v
```

即两条轴线在该处的距离不超过两处锥半径之和 (κ = 1 为几何上的选择, κ = 0.5 复现论文 Eq. 14, 见 2.5.3). 这正是论文 Eq. 14 背后的 "两半径之和" 原则, 只是把 "两个起点的间距" 换成了点到直线的精确距离, 并对每个 s 都成立, 而不只在起点处.

说明: 两锥在 x(s) 附近的横截面并不在同一平面, "距离 ≤ 半径之和" 是一阶近似, 误差为 O(α) 量级的倾斜修正 (对小夹角可忽略, 对大夹角区间本身很短). 本方案不比论文多引入新的近似.

### 2.2 二次不等式

点到直线距离的平方:

```
dist²(s) = |x(s) − a|² − ((x(s) − a)·d_j)² = sin²α · s² − 2 (u − c v) s + |a × d_j|²
```

R(s) = g s + h, 其中 g = τ (1 + c), h = −τ v. 两边平方 (在 R ≥ 0 的定义域内等价), 得 f(s) = A s² + B s + C ≤ 0:

```
A = κ² sin²α − g²
B = −2 [κ² (u − c v) + g h]
C = κ² |a × d_j|² − h²
```

sin²α 与 |a × d_j|² 用叉积计算, 避免 1 − c² 在小角度下的相消误差.

### 2.3 解集是单个区间

- dist(s) = |s d_i − a − ((s d_i − a)·d_j) d_j| 是 s 的仿射函数的范数, 因此是凸函数; R(s) 是线性函数. 所以 φ(s) = κ dist(s) − R(s) 是凸函数, 其下水平集 {φ ≤ 0} 是**一个区间** (可能为空, 可能无界).
- 定义域 D = {s ≥ s_min, s ≤ s_cap, t_min ≤ t(s) ≤ t_cap} 由线性约束构成, 也是区间, 且在 D 上 R > 0, 故 {f ≤ 0} ∩ D = {φ ≤ 0} ∩ D.
- 求根用数值稳定形式 q' = −(B + sign(B) √disc) / 2, 根为 q'/A 与 C/q'.
  - A > 0: 解集 [r1, r2] (disc < 0 时为空).
  - A < 0: disc < 0 时为全体实数; 否则为 (−∞, r1] ∪ [r2, ∞), 其中 R < 0 的那一支是平方引入的伪解. g ≥ 0 时 R 单调增, 取右支 [r2, ∞), 否则取左支. (由凸性, 在 D 上只可能有一支非空.)
  - A = 0: 退化为一次不等式 B s + C ≤ 0.
- 结果: [s_lo, s_hi] = 解集 ∩ D, 有效当且仅当 s_lo ≤ s_hi.

A 的符号就是 "大夹角 / 小夹角" 的连续版本: A < 0 ⇔ κ sin α < τ (1 + c), 此时两锥一旦开始重叠就永远不再分开 (区间无界); A > 0 时区间有界. 当 κ = 1 时, 该分界为 sin α ≈ 2τ ≈ θ_dvg, **恰好就是论文区分 Scenario-1 / 2 的阈值 α = θ_dvg**. 也就是说统一判据自动给出了论文的分界, 而不需要显式分情况.

### 2.4 定义域与上界

| 约束 | 取值 | 理由 |
|---|---|---|
| s ≥ s_min, t ≥ t_min | `min_range` (默认 1 m) | 排除传感器后方与自车附近; 也是剪枝角度模式的必要条件 (3.2.4). |
| s ≤ s_cap | min(max_range, r_i + cur_hit_margin), 默认 cur_hit_margin = ∞ | 与原代码一致, 允许当前命中点之后的样本. 是否保留见第 6 节. |
| t ≤ t_cap | min(max_range, r_j − ln w_min) | t > r_j − ln w_min 的样本 w_conf < w_min, 没有信息量. w_min = 0 时退化为 max_range. |

### 2.5 与论文两种情形的关系

#### 2.5.1 Scenario-1 (α > θ_dvg)

- 区间中心附近的特征点取两轴线的最近点 q = (u − c v) / sin²α. 由恒等式 (a × d_j)·(d_i × d_j) = (a·d_i) − (a·d_j)(d_i·d_j), 它与论文 Eq. 5 的 q_ij **完全相同** (单元测试 `test_large_angle_matches_eq5_and_is_short` 验证到 1e-9).
- 共面时区间半长约为 R(q) / (κ sin α). 下表为 q = t_q = 20 m, θ_dvg = 0.003 的数值 (来自参考实现):

| α | α / θ_dvg | κ = 1 的区间 [s_lo, s_hi] (m) | κ = 0.5 |
|---|---|---|---|
| 0.0015 | 0.5 | [6.67, ∞) | [4.00, ∞) |
| 0.003 | 1 | [10.0, ∞) | [6.67, ∞) |
| 0.006 | 2 | [13.3, 40.0] | [10.0, ∞) |
| 0.009 | 3 | [15.0, 30.0] | [12.0, 60.0] |
| 0.03 | 10 | [18.2, 22.2] | [16.7, 25.0] |
| 0.1 | 33 | [19.42, 20.62] | [18.87, 21.28] |
| 0.5 | 167 | [19.88, 20.13] | [19.75, 20.25] |
| 1.0 | 333 | [19.93, 20.07] | [19.86, 20.14] |

- **差异**: 论文在 α > θ_dvg 时把交集视为一个点. 统一判据表明, 只有 α ≳ 30 θ_dvg 时区间长度才小于 1 m 左右; θ_dvg < α < 30 θ_dvg 时重叠区可达数米甚至数十米, 期间 t(s) 相对 r_j 会变化, 标签也可能从 free 变到 occupied. 统一判据在区间内取多个样本 (2.6), 比单点更符合锥模型. 在 α ≫ θ_dvg 时两者一致.

#### 2.5.2 共面判定被隐含

- 对异面直线, dist(s) ≥ δ (公垂线长度), 若 κ δ > R(s) 在定义域内恒成立, 区间为空. 因此不需要单独的共面判定.
- 与论文的阈值相比: 论文要求 d_j 与参考平面的夹角 ≤ θ_dvg / 2, 等价于相邻束中心线在交点处离平面不超过 r_j (一个半径); 统一判据允许公垂线距离 ≤ (r_i + r_j) / κ (两个半径之和). κ = 1 时约为论文阈值的 2 倍. 这与论文 Eq. 14 使用的 "半径之和" 口径一致; 论文的共面阈值 (一个半径) 与 Eq. 14 (两个半径) 口径不同.
- 统一判据不存在问题 1 (法向量未归一化) 的阈值放大, 也不依赖参考平面是否存在 (问题 2).

#### 2.5.3 Scenario-2 (α ≤ θ_dvg) 与 κ

在共面且 s < q 时, dist(s) = (q − s) sin α 精确成立, t(s) = t_q − (q − s) c. 判据取等号:

```
κ (q − s) sin α = τ [ s + t_q − (q − s) c ]
```

论文 Eq. 13-14 (L = q − s, 相邻束起点深度 = t_q − L):

```
(q − s) sin(α/2) = τ [ s + t_q − (q − s) ]
```

- κ = 0.5 时, κ sin α = sin(α/2) cos(α/2), 再加上 c 与 1 的差别, 两式只差 O(α²) 的相对量. 单元测试 `test_small_angle_start_matches_eq15_with_paper_scale` 验证 κ = 0.5 时起点与 Eq. 15 相差 < 1e-4 · q.
- 但 Eq. 14 左边 L sin(α/2) 只是两起点间距 (弦长 2 L sin(α/2)) 的一半, 若 "两起点间距等于两处半径之和" 是本意, 应使用弦长, 对应 κ = 1. κ = 1 时起点更靠后 (重叠段更短), 例如上表 α = 0.5 θ_dvg 时起点从 4.0 m 变为 6.67 m.
- 支持 κ = 1 的另一证据: 只有 κ = 1 时有界 / 无界的分界才落在论文自己的 α = θ_dvg 上 (2.3).
- 参考实现默认 κ = 1 (`sep_scale = 1.0`), 并提供 κ = 0.5 复现论文公式. **请用户对照论文图示确认 Eq. 14 左边的几何含义** (第 6 节).
- 终点: 论文取 q 为终点. 统一判据在 A < 0 时区间无界, 实际被 t_cap / s_cap 截断. 原代码也只检查样本 ≥ 起点, 不检查 ≤ q, 因此本方案的上界与原代码行为一致, 与论文字面不同.

#### 2.5.4 原点重合与严格平行

- a = 0: u = v = 0, f(s) = (κ² sin²α − g²) s². 若 κ sin α ≤ τ (1 + c), 整条束都重叠 (同一方向被重复测量, 是很好的监督信号), 否则不重叠. 论文的构造在此无定义, 原代码产生伪样本.
- d_i ∥ d_j 且 a ≠ 0: sin²α = 0, A = −g² < 0, 区间为 [κ δ 被 R 覆盖的位置, ∞) ∩ D. 最近点 q 不存在, 锚点改用 s_lo.

### 2.6 区间内采样

每个束对使用固定数量的槽位 (便于向量化), 槽位越出 [s_lo, s_hi] 或与前面槽位重复 (相差 ≤ 1e-6 m) 时被屏蔽.

锚点 s_c: q 夹到 [s_lo, s_hi] 内 (q 存在时), 否则取 s_lo. 对大夹角, s_c 就是 Eq. 5 的交点; 对小夹角, s_c 就是论文 Scenario-2 的终点 q.

| 模式 | 槽位 | 说明 |
|---|---|---|
| `paper` (默认) | s_c, r_i, s_pj, (r_i + s_pj)/2, (r_i + s_c)/2, (s_pj + s_c)/2 | s_pj = d_i · p_j = u + r_j c 是 p_j 在 d_i 上的正交投影. 后 5 个即论文 o_k1..o_k5 (以 s_c 代替 q). 大夹角时区间很短, 通常只剩 s_c, 与论文 Scenario-1 一致; 中等夹角时落入区间的论文点也会被保留. |
| `uniform` | s_c 加 n 个等距点, n = clamp(⌈长度 / step⌉, 1, uniform_max) | 固定步长并设上限, 短区间只有 1~2 个点, 避免大夹角时产生大量重复样本. |

不建议 "每对固定点数": 大夹角区间只有厘米级, 固定点数会产生近似重复的样本, 在损失中相当于加权.

### 2.7 投影与标签

每个样本 s 正交投影到相邻束轴线: t(s) = c s − v (即论文 "投影到 d_j^t"). δ = t(s) − r_j:

- δ < −hit_tol: free, w_conf = 1.
- 否则 w_conf = exp(−max(δ, 0)); w_conf ≥ λ_occ 为 occupied (δ ≤ −ln λ_occ = 0.105 m), 否则 unknown.
- w_conf < w_min 的样本丢弃 (默认 0.1 与原代码一致; 论文无此截断, 设 0 可关闭).

hit_tol (默认 1e-6 m) 是为了让 "恰好在命中点" 的样本不因舍入误差被判为 free (静止自车时同一束与自身重叠, δ 的舍入误差约 1e-16).

### 2.8 数值稳定性

| 情形 | 风险 | 处理 |
|---|---|---|
| 平行 / 近平行 | 交点公式除以 sin²α → 0 | 区间求解不除以 sin²α, A 可正可负可为 0, 分支覆盖; q 只用于锚点, sin²α ≤ 1e-24 时视为不存在. |
| 原点重合 | 参考平面不存在 | 二次式在 a = 0 时仍有定义; 剪枝切换到角度模式 (3.2.4). |
| 小角度相消 | 1 − c² 精度差 | sin²α, \|a × d_j\|² 用叉积. 全程 float64. |
| 二次求根相消 | 经典求根公式在 B² ≫ 4AC 时失精度 | 稳定形式 q'/A, C/q'; A ≈ 0 时 q'/A 很大, 被定义域截断即可. |
| 平方引入伪解 | R < 0 的区域满足 f ≤ 0 | 定义域保证 R > 0; A < 0 时按 g 的符号选支. |
| 远距离 | 半径与距离同阶增长, 无特殊问题 | 由 s_cap, t_cap 截断. |
| 区间端点在命中点之外 | 当前命中点之后的空间在当前帧中被遮挡; 相邻命中点之后 w_conf 衰减 | t_cap 由 w_min 推出; s_cap 可选 r_i + margin (第 6 节). |
| 传感器后方相交 | 交点 s < 0 或 t < 0 | 由 s ≥ s_min, t ≥ t_min 排除 (测试 `test_behind_sensor_rejected`). |
| 命中点上的舍入 | δ = 0 被判为 free | hit_tol. |

### 3.2 无漏检候选剪枝

#### 3.2.1 引理 (平面束界)

设 a ≠ 0. 记 Π_i 为过当前原点, 包含 d_i 与 a 的平面, Π_j 为过当前原点, 包含 d_j 与 a 的平面 (Π_j 包含整条相邻束轴线, 因为 a ∈ Π_j 且 d_j ∥ Π_j). 若 (i, j) 在某个 s ≥ 0, t(s) ≥ 0 处重叠 (2.1 判据), 则

```
|n_i · d_j| ≤ 2τ/κ   或   |n_j · d_i| ≤ 2τ/κ
```

其中 n_i, n_j 为 Π_i, Π_j 的单位法向.

证明: 记 y = a + t d_j 为垂足. x(s) ∈ Π_i, 故 dist(x, 轴线 j) = |x − y| ≥ dist(y, Π_i) = |n_i · y| = t |n_i · d_j| (n_i ⊥ a). 同理 x 到 Π_j 的距离 s |n_j · d_i| ≤ |x − y|. 若 t ≥ s, 则 κ t |n_i · d_j| ≤ R = τ (s + t) ≤ 2τ t; 若 s ≥ t, 则 κ s |n_j · d_i| ≤ 2τ s. 证毕.

该界只用到 2.1 的判据本身, 不引入额外近似, 也不需要 s_min. 它是论文共面判定的严格版本: 法向量是**归一化**的, 并且对称地考虑了两个平面.

#### 3.2.2 一维化: 方位角索引

所有 Π_i 与 Π_j 都包含直线 (0, a), 属于同一个**平面束**, 可以用绕轴 e = a / |a| 的方位角 ψ 参数化. 以 e 为极轴, 方向 d 写成 (sin γ cos ψ, sin γ sin ψ, cos γ), 则 n_i = (−sin ψ_i, cos ψ_i, 0), 且

```
|n_i · d_j| = sin γ_j · |sin(ψ_i − ψ_j)|,     |n_j · d_i| = sin γ_i · |sin(ψ_i − ψ_j)|
```

条件只依赖 ψ 的差 (以 π 为周期) 与各自的 sin γ. 于是:

1. 对相邻帧方向按 ψ mod π 排序 (O(M log M)), 拼接 [ψ − π, ψ, ψ + π] 处理周期.
2. 分支 B (s ≥ t): 对每个当前束 i, 窗口半宽 W_i = arcsin(min(1, thr / sin γ_i)), 用 `searchsorted` 找出 ψ_j ∈ [ψ_i − W_i, ψ_i + W_i] 的全部 j, 再用精确谓词 sin γ_i |sin Δψ| ≤ thr 过滤.
3. 分支 A (t ≥ s): 对每个相邻束 j 对称地查询当前束, 谓词 sin γ_j |sin Δψ| ≤ thr, 并剔除已满足分支 B 谓词的对, 两支并集无重复.
4. 候选对交给 2.3 的精确区间求解.

复杂度 O((N + M) log(N + M) + K), K 为候选数. 窗口加 1e-9 rad 余量, 阈值乘 (1 + 1e-9) 再加 1e-12, 以吸收 float64 舍入, 保证候选集包含精确判据接受的所有对.

#### 3.2.3 漏检保证

- 在精确算术下无漏检 (引理). 在 float64 下, 窗口与阈值的余量远大于舍入误差.
- 单元测试 `test_pruned_equals_dense_and_chunk_invariant` 在 5 类场景 (运动, 静止, 1e-4 m 微小基线, 随机方向, 竖直基线) × 3 组参数下, 比较剪枝与 N×M 全量求解的输出, **逐位相同**. 另外离线跑了 40 个随机基线 (尺度 1e-4 ~ 5 m) × 3 组参数共 120 例, 无一不一致.
- sin γ → 0 (方向几乎沿基线) 时窗口退化为整个周期, 仍然无漏检, 只是这些束不被剪枝; 这类束在立体角上占比约 (thr)², 数量很少.

#### 3.2.4 原点重合 (|a| ≤ baseline_eps)

平面束无定义. 改用角度界: dist(x, 轴线 j) ≥ s sin α − |a|, t ≤ s + |a|, 得 sin α ≤ 2τ/κ + |a| (1 + τ/κ) / s_min. 再利用 "d_j 到过 z 轴与 d_i 的平面的距离 ≤ sin α" (对 i, j 对称), 用同一套方位角索引 (轴取 z), 两个谓词取**与**. 这里用到 s ≥ s_min > 0.

#### 3.2.5 与 range image 光栅化方案的关系

任务中提出的 "在当前传感器球面 range image 上光栅化相邻束中心线的投影弧" 与上面的分支 B 是同一件事: Π_j 与单位球的交线就是相邻束 j 从当前原点看去的投影弧所在的大圆, 分支 B 的谓词就是 "d_i 落在该大圆的宽度为 thr 的带内". 但光栅化方案要做到无漏检, 还需要:

- 只用弧段 (而非整个大圆) 时, 带宽要随弧上点而变: 由 R / s = τ (1 + t / s) 推出, 近当前原点而远离相邻原点的弧段 (t / s 大) 带宽可以很大, 若用常数带宽必须取 τ (1 + t_cap / s_min), 约 0.08 rad, 剪枝效果很差.
- 像素量化要求再膨胀半个像素对角线, 且 nuScenes 的 range image 投影本身有多点落入同一像素的冲突.
- 只做单向投影会漏掉 t ≥ s 的情况, 必须同时在相邻帧 range image 上做反向光栅化 (即分支 A).

方位角索引把这三点都化掉了 (不用弧段, 没有像素, 两个分支对称), 而且只用 sort / searchsorted / repeat_interleave, 在 PyTorch 中 CPU / GPU 通用. 代价是它用整个大圆而不是弧段, 候选精度 (真实重叠对 / 候选对) 在合成数据上约 15%.

### 3.3 算法流程与分块

```
for 每个当前帧 (多 GPU 按场景划分):
    当前帧方向与距离 (float64)
    for 每个相邻帧 t:
        a = a_t − a_0
        若 |a| > eps: 轴 = a/|a|, thr = 2τ/κ          (平面束模式, 两分支取或)
        否则:          轴 = z,    thr = 角度界           (角度模式, 两谓词取与)
        计算 ψ, sin γ, 排序, searchsorted 得到每个查询的窗口 [lo, lo + cnt)
        按 cnt 的前缀和把查询切成若干块, 每块候选数 ≤ pair_chunk
        for 每块:
            展开为 (i, j) 对, 精确谓词过滤
            2.3 区间求解 -> 压缩到有效对 -> 2.6 采样 -> 2.7 标签
    拼接, 按 (帧, i, j, 槽位) 排序输出
```

- 分块只改变计算的分组, 区间求解与标签都是逐对的逐元素运算, 因此分块结果与不分块结果**逐位相同** (测试中 pair_chunk = 997 与 1e8 比较).
- 显存上界约为 pair_chunk × (约 40 个 float64 / int64 临时数组) × 8 B; pair_chunk = 2e6 时约 0.6 GB, 加上排序后的输出.

### 3.4 复杂度与显存

| 项目 | 原实现 (nuScenes) | 本方案 |
|---|---|---|
| 每对帧计算 | O(NM) = 1.2e9 对, 稠密 | O((N+M) log M + K), 合成数据 K ≈ 1.0e7 (0.87% NM) |
| 每对帧显存 | ≥ 12 GB (估算) | ≈ pair_chunk × 320 B, 默认约 0.6 GB, 可调 |
| 每当前帧候选数 (12 帧) | 1.4e10 | 1.25e8 |
| 精确求解后的重叠对 | 未知 | 每对帧约 1.55e6 |

### 3.5 实测与估算

**CPU 实测** (本容器, 4 线程, `python -m top_label.benchmark --device cpu`, 合成序列, 自车每帧前进 3 m, 测距噪声 0.02 m):

| 规模 | 剪枝 | 每当前帧耗时 | 候选对 | 输出样本 |
|---|---|---|---|---|
| 16 环 × 360, 5760 点, 4 相邻帧 | phi | 0.41 s | 1.12e6 (0.85%) | 206664 |
| 同上 | none (稠密) | 39.5 s | 1.33e8 | 206664 (逐位相同) |
| 32 环 × 1080, 34560 点, 12 相邻帧 | phi | 25.7 s | 1.25e8 (0.87%) | 1.68e7 (free 88.7%, unknown 9.5%, occupied 1.8%) |

单对帧剖析 (34560 点): 候选生成 0.40 s, 精确求解 + 采样 2.74 s, 即逐对计算占约 87%.

**GPU 估算 (未实测)**: 精确求解约 100 个 float64 逐元素 kernel, 每对约 2~3 KB 内存流量. 每当前帧 1.25e8 候选对约 250~400 GB 流量, A100 (约 1.5 TB/s) 上约 0.2~0.4 s, 加上 kernel 启动开销 (默认块大小下每帧约 60 块 × 数百 kernel) 合计估计 0.3~0.6 s. 按 3.4 万个当前帧, 单卡约 3~6 小时, 8 卡按场景并行约 0.5 小时. 用 `torch.compile` 融合逐元素运算可再降低 5~10 倍流量 (未实现). 消费级显卡 float64 算力只有 1/64, 但该负载以内存带宽为主, 预计影响有限; 若成为瓶颈, 可把候选生成改为 float32 (同时放大余量), 精确求解保留 float64.

与原实现相比, 在 GPU 上的提速估计只有数倍 (原实现的稠密部分也是带宽瓶颈, 估计每帧 0.5~1 s), 主要收益是: 显存从 ≥ 12 GB 降到 < 2 GB (可以一卡多进程或增大块), 去掉同步与 empty_cache, 结果正确, 以及有了进一步融合的空间. 这一结论需要用户在 GPU 上运行 benchmark 核实.

### 3.6 多 GPU, 数据加载与输出

- **按场景并行**: 每个进程 / GPU 处理若干完整场景. 一个场景约 40 个 key frame, 一次性读入并变换到全局坐标 (约 40 × 3.45 万 × 3 × 4 B ≈ 16 MB), 之后每个当前帧只需在 GPU 上做一次刚体变换, 消除每个 sweep 被重复读取约 12 次的问题.
- **CPU 预取**: 用 DataLoader (num_workers > 0) 以场景为单位预取并解码点云与位姿, 与 GPU 计算重叠.
- **多个相邻帧批处理**: 各相邻帧的轴 a 不同, 方位角索引需分别构建 (O(M log M), 很便宜), 但精确求解可以把多帧的候选对拼成一个大块一起算, 以减少 kernel 启动次数. 参考实现目前按帧循环, 块内已是大批量.
- **输出量 (重要风险)**: 合成数据上每个当前帧 1.68e7 个样本, 每样本约 10 B (索引 2 + 帧号 1 + 相邻索引 2 + 深度 2 + 状态 1 + 置信度 2), 约 170 MB / 帧, 3.4 万帧约 5.7 TB, 不可接受. 原代码的共面带更宽, 也对每个相交对生成样本, 样本量可能是同一量级, 但无法在本容器核实. 可选的削减方式 (未实现, 需用户决定): (a) 每个 (i, 相邻帧) 按当前束深度分箱去重, 只保留每箱置信度最高的样本; (b) 在预处理阶段就按类别下采样 free (训练时 `mo_samples_free_pct` 已做类似的平衡); (c) 改为训练时在线生成, 这需要每帧耗时降到 0.1 s 以下, 依赖 3.5 中的融合优化.
