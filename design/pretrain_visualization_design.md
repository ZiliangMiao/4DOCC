# TOP 预训练结果可视化设计

> 状态: 草案
> 范围: 只描述逻辑与判读方法, 不绑定任何具体实现.

---

## 1. 目的与范围

**目的**

- 用 "可视化 + 配套定量指标" 诊断 TOP 预训练是否学到了时序占据 (temporal occupancy) 信息.
- 同时产出可用于论文与汇报的插图.

**不在范围内**

- 下游 MOS 微调评测. 预训练有效性的最终证据仍是下游 few-shot 结果, 本设计只做诊断与解释.
- 模型结构的修改.
- 具体实现 (模块划分, 接口, 文件).

**两个方案**

| 方案 | 场景 | 回答的问题 | 定位 |
|---|---|---|---|
| 方案 1 | LiDAR 静止时刻的一个小扇面 | 模型能否预测整条线束上的观测在过去/未来如何变化 | 主结果 |
| 方案 2a | 运动物体上的点 | 模型能否在无标签条件下区分运动点与静止点 (零样本运动线索) | 主结果 |
| 方案 2b | 运动物体的扫掠空间 | 模型预测的占据能否随时间跟随物体移动 | 演示 |

## 2. 背景: 预训练任务回顾

### 2.1 符号

| 符号 | 含义 |
|---|---|
| t0 | 当前时刻, 简记为 t = 0 |
| T | 相邻时刻集合, {±0.5, ±1.0, ..., ±3.0} s (2 Hz, 过去 6 帧与未来 6 帧) |
| a^t | t 时刻传感器原点 (已对齐到当前帧坐标系) |
| d_i, r_i, p_i | 当前帧第 i 条线束的方向, 测距, 命中点, p_i = a^0 + r_i·d_i |
| f_i | 编码器输出的当前帧第 i 个点的特征 |
| o | 查询点 (x, y, z, t) |
| PE(o) | 4D 正余弦位置编码 |
| h | 浅层 MLP 解码器, 输出 free / occupied / unknown 三类概率 |
| θ_dvg | 线束发散角 (nuScenes 为 0.003 rad) |
| λ_occ | occupied 置信度阈值 0.9, 对应命中点之后 0.105 m 的 occupied 带 |

### 2.2 任务定义

1. **编码.** 输入为过去与当前共 6 帧点云, 每个点附加时间成为 4D 点. 编码器只输出当前帧各点的特征 f_i.
2. **查询点.** 查询点位于当前帧线束 i 上, 且与相邻时刻 t 的某条线束相交.
3. **标签.** 由 t 时刻那条线束的观测决定:
   - 在其命中点之前为 free.
   - 在命中点之后 0.105 m 内为 occupied.
   - 再往后为 unknown.
4. **预测.** u = h(PE(o) + f_i).
5. **辅助项.** 在当前束上重建 t = 0 时的 free / occupied.

**本质.** 这是一个条件分类问题: 给定 "当前某条线束上的固定空间位置" 和 "某个相邻时刻 t", 预测 t 时刻 LiDAR 在该位置的观测状态.

## 3. 可解码范围

**这是整个设计的前提.** 可视化只能在模型被训练过的范围内下结论. 超出范围的查询必须显式标注, 不能用来否定预训练.

### 3.1 可以查询的

- **线束:** 当前帧的线束 i, 使用其特征 f_i.
- **位置:** 线束 i 上的点 o = a^0 + d·d_i, d 为沿束深度.
- **时刻:** t ∈ T ∪ {0}. T 内相邻时刻之间的值属于插值, 需要单独标注.

### 3.2 解码出来的是什么

- 解码结果是 **观测状态**, 不是物理占据.
- free / occupied / unknown 依赖 t 时刻传感器的视点. 例如被遮挡的位置是 unknown, 即使物理上有物体.
- 模型的输入不包含未来位姿.
  - 自车运动时, 未来视点对模型而言是不确定的, 预测里混有对自车运动的隐式猜测.
  - 自车静止时, 这种歧义消失. 这正是方案 1 的动机.

### 3.3 不能查询的

| 不能查询 | 原因 |
|---|---|
| 历史帧线束 | 编码器在历史点上虽有输出, 但解码器只用当前帧特征训练过, 历史点特征从未被监督 |
| 不在任何当前线束上的空间点 | 找不到对应的 f_i. 用最近邻特征硬凑属于分布外查询 |
| T 之外的时刻 (\|t\| > 3 s) | 外推 |

### 3.4 沿束的分布区域

```
 a^0 ──────────────────────────●──────────────────────────────▶ d_i
                              p_i (深度 r_i)
 |<-------- 区域 B ---------->|<----------- 区域 A ------------>|<-- 区域 D -->
           t≠0, d < r_i                 t≠0, d ≥ r_i              无监督远端

 区域 C: t = 0, d ∈ [0, r_i + 0.105]   (由当前占据重建项监督)
```

| 区域 | 条件 | 是否在训练分布内 | 对应的物理事件 |
|---|---|---|---|
| A | t≠0, d ≥ r_i | 是 | 消遮挡: 当前挡在束上的物体在 t 时刻离开, 其后方变为 free |
| B | t≠0, d < r_i | 取决于预训练配置 (见下) | 遮挡出现: 物体在 t 时刻进入该束, 命中点前方出现 occupied |
| C | t = 0 | 是 (重建项) | 当前几何 |
| D | 远超相邻命中点 | 否 (若训练时丢弃了低置信度 unknown 样本) | 无 |

**区域 B 的说明.**
- 按论文定义, 命中点前方的重叠点也属于训练样本, 区域 B 在分布内.
- 若某次预训练只采样命中点及其后方的重叠点, 区域 B 就超出分布.
- 可视化前必须确认所用模型属于哪种情况. 见第 10 节.

### 3.5 精度上限

- 解码器的输入只有 f_i 和查询点 **绝对坐标** 的位置编码, 没有查询点相对 p_i 的偏移.
- 稀疏卷积特征近似平移等变, 模型只能通过点密度, 扫描线间距等间接线索估计 r_i.
- occupied 带只有 0.105 m 宽, 因此沿束的状态边界可能是模糊的.
- 判读时应区分两件事:
  - "事件判断正确" (该束是否会变, 怎样变).
  - "边界定位精确" (变到哪个深度).

## 4. 设计原则

1. **只在定义域内下结论.** 每个查询都打上区域标签 (A / B / C / D, 插值时刻), 所有指标按区域分开统计.
2. **每张图配一个指标, 每个指标配一个基线.** 只有图没有数字的结论不成立.
3. **过去与未来分开.** 过去时刻的扫描本身就在输入里, 模型可以 "查表". 只有未来时刻才是真正的预测.
4. **变化与不变分开.** 大部分空间不随时间变化, "照抄当前" 就能得到很高的总体分数. 关键结论只看变化的部分.
5. **只用未参与预训练的数据.** 预训练用了全部训练集, 可视化样本只从验证集中选.
6. **先验证真值, 再评估模型.** 真值生成本身可能出错, 必须先单独可视化真值并做一致性检查.

## 5. 公共组件

### 5.1 样本池

- 数据来自验证集 (未参与预训练).
- 每个样本需要 [t0 − 3 s, t0 + 3 s] 内全部 13 个关键帧.
- 每个样本需要以下信息:
  - 位姿.
  - 每个点的激光器编号 (ring) 与方位角. 若数据不提供 ring, 按俯仰角聚类恢复.
  - 运动标签 (MOS).
  - 物体框 (含 instance 关联).

### 5.2 输入构建与编码

1. 取 t0 及之前共 6 帧, 用位姿变换到当前帧坐标系. 过滤自车点与范围外的点.
2. 与预训练保持一致, 但 **不做任何数据增强**.
3. 编码一次, 缓存当前帧全部点的特征 f_i.

### 5.3 查询与批量解码

- 一个查询由 (i, d, t) 决定, o = (a^0 + d·d_i, t). t 使用相对当前帧的真实时间戳 (秒).
- 查询量通常为千万量级, 分块批量送入解码器.
- 每个查询保存以下内容:
  - 三类概率.
  - argmax 类别.
  - 区域标签.
  - 过去 / 未来标签.

### 5.4 由预测派生的量

| 派生量 | 定义 | 用途 |
|---|---|---|
| 硬预测距离 r̂_i^t | 沿束从近到远, 第一个 argmax 为非 free 的深度, 且其后连续 K = 2 个采样点同为非 free | 与真值测距比较 |
| 软预测距离 r̄_i^t | d_min + Σ_k P_free(d_k)·Δd | 对边界模糊不敏感的距离估计 |
| 时间敏感度 S_i^t | JS 散度 (P(· \| o, t), P(· \| o, 0)) 沿束取平均 | 检查模型是否使用了时间条件 |
| 翻转分数 s_i | max_{t ∈ T'} P_free(p_i, t), T' 为过去或未来子集 | 点级运动线索 (方案 2a) |
| 最早翻转时刻 τ̂_i | 使 P_free(p_i, t) > 0.5 的最小 \|t\|, t ∈ T' | 与物理翻转时刻比较 (方案 2a) |

### 5.5 真值

共三种, 适用条件不同.

**G1: 共线真值 (仅限静止视点)**
- 条件: \|a^t − a^0\| < ε, 且朝向变化可忽略.
- 匹配规则: 对当前束 i, 在扫描 t 中找同一 ring, 方位差最小且 ≤ τ_az 的束 j. τ_az = min(θ_dvg, 方位分辨率 / 2).
- 真值剖面: 在束 i 上, d < r_j^t 为 free, r_j^t ≤ d ≤ r_j^t + 0.105 为 occupied, 之后为 unknown.
- 优点: 整条束都有稠密真值.
- 若找不到匹配束, 记为 "无真值". 无回波的方向在数据中不存在, **不能当作 free**.

**G2: 交点真值 (一般视点, 与预训练标签定义一致)**
- 对当前束 i 与扫描 t 的束 j:
  1. 判断两束是否在发散角容差内共面.
  2. 若夹角 > θ_dvg, 取两中心线的交点.
  3. 若夹角 ≤ θ_dvg, 取交叠段并在段上采样.
  4. 按束 j 的测距给出状态.
- 只有交点处有真值, 结果是稀疏的.
- **退化情形.** 两帧原点几乎重合时, 由 "当前束 + 两原点连线" 确定的参考平面不存在, 共面判定与交点计算都会失效.
  - 规则: 当 \|a^t − a^0\| < ε 时, 强制改用 G1.
  - 共面判定所用的平面法向必须先归一化, 否则判定阈值会随束方向与原点连线的夹角被放大.

**G3: 物体框真值 (物理占据, 与视点无关)**
- 用相邻关键帧中同一 instance 的框 box_t.
- 判定: 点 o 在 box_t 内即为 "被该物体占据".
- 它描述的是物理事实, 不是观测. 被遮挡的位置在 G3 中可能是占据, 在 G2 中则是 unknown.
- 用途: 补全稀疏真值, 解释 G2 与预测之间的差异.

### 5.6 对照与基线

| 编号 | 名称 | 定义 | 用于排除的解释 |
|---|---|---|---|
| B0 | Persistence | 任意 t 的预测都等于当前观测 (r̂^t = r^0) | "只学到了当前几何" |
| B1 | 时间消融 | 同一模型, 把查询时间 t 替换为 0 | "模型忽略时间条件" |
| B2 | 静止物体对照 | 与运动物体按类别, 距离, 点数匹配的静止物体 | "翻转分数只反映物体类别或距离" |
| B3 (可选) | 随机编码器探针 | 冻结随机初始化的编码器, 只训练同结构的解码器, 训练步数相同 | "解码器本身就能完成任务, 与编码器预训练无关" |

### 5.7 真值自检

在评估任何模型之前, 对每个选中样本先做以下检查:

1. 把 G1 剖面与原始扫描叠加显示, 确认匹配束的测距与扫描点一致.
2. 在静止窗口中, 比较 G1 与 G2 在共同位置上的一致率. 若一致率低, 说明交点规则在该场景退化.
3. 若能获得预训练时使用的标签, 与 G1 / G2 做同样比较.
   - 若静止场景的训练标签与 G1 明显不符, 说明模型在静止场景学到的是噪声目标.
   - 这种情况下, 方案 1 的结果需要单独解读.

## 6. 方案 1: 静止 LiDAR 扇面

### 6.1 动机与假设

- 传感器在 [t0 − 3 s, t0 + 3 s] 内静止, 因此 t 时刻视点等于当前视点, 3.2 节所述的歧义消失.
- 每条当前束在每个 t 都有整束的 G1 真值, 这是唯一能拿到 "整束稠密真值" 的场景.
- 扇面取全部俯仰角 (所有 ring) 和一小段方位角, 范围小, 便于逐束观察.

### 6.2 选样

1. **静止窗口.** 13 个关键帧满足以下两点:
   - max_t \|a^t − a^0\| < 0.05 m.
   - 最大朝向变化 < 0.2°.
2. **动态扇面.**
   - 方位宽度 W = 20°–30°, 以 5° 步长在 360° 上滑动.
   - 扇面得分 = 窗口内 "变化 (束, 时刻) 对" 的数量 (定义见 6.3).
   - 取得分最高的扇面. 优先选择同时包含 "离开" 与 "进入" 两类事件的窗口, 典型场景是等红灯时横穿的行人或车辆.
3. **静态对照扇面.** 同一窗口中变化对数接近 0 的扇面.
4. **随机扇面.** 另取若干随机扇面, 用于检查选样偏差.

### 6.3 事件分类

对每个 (束 i, 时刻 t), 用 G1 测距 r_i^t 与当前测距 r_i^0 比较, 阈值 τ_change = 0.3 m (大于两倍 occupied 带宽加上测距噪声):

| 事件 | 条件 | 真值上的表现 | 证据所在区域 |
|---|---|---|---|
| 不变 | \|r^t − r^0\| ≤ τ_change | 与当前一致 | A, B 均应保持当前状态 |
| 离开 (消遮挡) | r^t > r^0 + τ_change | [r^0, r^t) 在 t 时刻变为 free | 区域 A |
| 进入 (遮挡) | r^t < r^0 − τ_change | [r^t, r^t + 0.105] 在 t 时刻变为 occupied, 其后变为 unknown | 区域 B |
| 无真值 | 找不到匹配束 | — | 不计入统计 |

**这个对应关系是判读的核心.**
- "离开" 事件只能在区域 A 被预测.
- "进入" 事件只能在区域 B 被预测.
- 若区域 B 不在训练分布内, "进入" 类的失败不说明预训练无效.

### 6.4 查询网格

- **线束:** 扇面内全部当前线束.
- **深度:** d ∈ [d_min, D_i], 其中 d_min = 0.5 m, D_i = max(r_i^0, max_t r_i^t) + 3 m. 步长 Δd = 0.05 m, 不大于 occupied 带宽的一半, 保证该带至少被采样两次.
- **时刻:** T ∪ {0}, 共 13 个. 可选加入 T 内相邻时刻的中点, 标注为插值.
- **规模:** 约 32 × 90 束 × 600 深度 × 13 时刻 ≈ 2 × 10^7 次查询.

### 6.5 可视化输出

1. **Range image 面板** (横轴方位, 纵轴 ring).
   - 每列一个时刻 t, 从 −3 s 到 +3 s.
   - 每行依次为: G1 测距 r^t, 硬预测 r̂^t, 基线 B0 的 r^0, 带符号误差 r̂^t − r^t.
2. **事件图.** 同样的布局, 每个像素按 "真值事件类型 × 预测是否正确" 着色.
3. **线束剖面热力图.** 选变化最大的 k 条束.
   - 横轴为时刻, 纵轴为深度, 颜色 RGB = (P_free, P_occ, P_unk).
   - 叠加 G1 边界线 r^t 与当前测距线 r^0, 并用底纹区分区域 A / B.
4. **3D 点云序列.**
   - 每个 t 渲染预测点 a^0 + r̂^t·d_i, 按误差着色, 叠加 t 时刻真实扫描点.
   - 按时间顺序合成动画.
5. **时间敏感度图.** 每条束的 S_i^t 与真值是否变化的散点图.

### 6.6 指标

所有指标按以下维度分别给出: 过去 / 未来, 事件类型 (不变 / 离开 / 进入), 区域 (A / B / C).

| 指标 | 定义 |
|---|---|
| 距离误差 | \|r̂^t − r^t\| 的均值与中位数. 误差 ≤ 0.2 m 与 ≤ 0.5 m 的比例 |
| 事件分类 | 由 r̂^t 与 r^0 按 τ_change 判定预测事件, 得到 3×3 混淆矩阵, 计算各类召回率与宏平均 F1 |
| 沿束三分类 | 每个查询点与 G1 比较, 计算三类的准确率与 IoU |
| 时间敏感度 | 变化束与不变束上 S_i^t 的均值之比 |

**基线对比:**
- B0 在 "不变" 类上完美, 在 "离开" 与 "进入" 类上召回率为 0.
- B1 衡量模型是否使用了时间条件.

### 6.7 判读标准

- **最低要求.** "不变" 束上的距离误差接近 B0, 说明当前几何已学好.
- **核心证据.** 在未来时刻, "离开" 类 (区域 A) 的召回率显著高于 0, 且变化束上的距离误差显著优于 B0.
- **附加证据.** 若区域 B 在训练分布内, "进入" 类的召回率显著高于 0.
- **时间条件.** 变化束上的 S_i^t 明显高于不变束. 若两者相近, 说明模型对时间不敏感.

### 6.8 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 静止场景在训练集中占比低 | 分布偏移 | 同时报告方案 2 的自车运动样本 |
| 预训练时静止场景的标签退化 (见 5.5 的退化情形) | 模型在静止场景学到噪声目标 | 先做 5.7 的真值自检, 结论单独解读 |
| 不变束占绝大多数 | 总体指标虚高 | 只用分事件类型的指标下结论 |
| 按变化量选扇面带来选样偏差 | 结果偏乐观 | 同时报告随机扇面 |

## 7. 方案 2: 运动物体

### 7.1 概念澄清

- **解码只用当前线束的特征.** 从当前点出发与历史线束求交, 历史线束只决定查询位置和真值, 不参与预测. 用历史点特征解码不在模型能力范围内 (见 3.3).
- **时刻同时取过去与未来.** 只看过去偏弱, 因为过去扫描在输入里. 未来扫描对编码器不可见, 是更强的证据.
- **只从物体点出发无法渲染运动.** 物体在 t 时刻所在的位置, 大多落在其他当前束的命中点前方 (这些束现在打到背景上), 属于区域 B.

因此拆为两部分:
- **2a 点级运动线索:** 区域 A 与边界, 在分布内, 作主结果.
- **2b 物体运动渲染:** 含区域 B, 作演示.

### 7.2 选样

**运动物体条件**

| 条件 | 阈值 | 理由 |
|---|---|---|
| 运动点比例 | 去掉框底 0.2 m (地面点) 后, 框内运动点比例 ≥ 95% | "全部为运动点" 过严: 框内常含地面点与速度模糊的点 |
| 点数 | ≥ 30 (2b), 2a 不限但分桶统计 | 保证可视化可读 |
| 速度 | ≥ 1 m/s | 保证 ±3 s 内有明显位移 |
| 距离 | ≤ 40 m | 远处线束稀疏, 交点真值过少 |
| 时间完整性 | [t0 − 3 s, t0 + 3 s] 内每个关键帧都有该 instance 的框 | G3 需要 |

**静止对照物体.** 按类别, 距离, 点数与运动物体匹配, 速度 < 0.2 m/s.

**自车状态.** 优先选自车静止的样本 (真值稠密, 视点歧义小). 另选自车运动的样本展示一般情况.

**规模.** 2a 的定量统计至少使用 200 个运动物体加同等数量的匹配静止物体, 用 bootstrap 给出置信区间. 2b 选 3–5 个代表性物体.

### 7.3 方案 2a: 点级运动线索

**查询**
- 对物体上每个当前点 p_i, 查询 d ∈ {r_i, r_i + δ}, δ = 0.05 m (命中点与紧邻其后的位置, 属区域 A 与边界).
- 时刻取 T 中全部 12 个相邻时刻.

**派生量**
- s_i^past, s_i^future: 分别在过去与未来子集上计算的翻转分数.
- τ̂_i^past, τ̂_i^future: 预测的最早翻转时刻.

**真值**
- **观测真值:** 在 p_i 处用 G2. 扫描 t 中经过 p_i 附近的束有三种情况:
  - 命中点在 p_i 之后: free.
  - 命中点在 p_i 处: occupied.
  - 命中点在 p_i 之前 (被遮挡): unknown.
  - 没有相交束: 无真值.
- **物理翻转时刻:** 用 G3. τ*_i^future = min{t > 0, t ∈ T : p_i ∉ box_t}, 过去方向同理. 这是逐关键帧判定, 不需要匀速假设.

**指标**

| 指标 | 定义 | 对照 |
|---|---|---|
| 运动判别 | s_i 区分运动物体点与匹配静止物体点的 AUROC 与 AP, 过去与未来分开 | B2 |
| 观测一致性 | (i, t) 上预测类别与 G2 的三分类准确率 | B0, B1 |
| 翻转时刻一致性 | \|τ̂_i − τ*_i\| (以帧为单位) 的分布, 精确匹配率, 点级 Spearman 相关 | B0 (永不翻转) |

分层统计维度:
- 类别 (车辆 / 行人 / 自行车).
- 点数: ≤ 19, 20–49, ≥ 50. 对应论文中 "大多数运动物体点数很少" 的论点.
- 距离, 速度, 自车静止 / 运动.

**可视化输出**
1. 当前帧物体点云, 分别按 s_i^future, s_i^past, τ̂_i 着色, 旁边并列物理翻转时刻 τ*_i 的着色.
2. 同一场景的静止对照物体, 使用相同色标.
3. 运动点与静止点的 s_i 分布直方图, 以及 ROC 曲线.
4. 翻转时刻的二维直方图: 横轴 τ*, 纵轴 τ̂.

**判读**
- 未来方向 AUROC 显著高于 0.5, 且显著高于 B1, 才是 "零样本运动线索" 的直接证据.
- 过去方向更高属于预期 (输入中有历史扫描), 不能单独作为结论.

### 7.4 方案 2b: 物体运动渲染

**扫掠空间**
- V = ∪_{t ∈ T ∪ {0}} box_t, 再向外扩 0.3 m.

**查询线束**
- R1: 命中该物体的当前线束.
- R2: 线段 [a^0, p_i] 穿过 V 的当前线束. 这些束现在打到背景上, 但经过物体曾经或将要所在的位置.

**查询点**
- 在 R1 ∪ R2 上以 0.1 m 步长采样, 只保留落在 V 内的点.
- 时刻取 T ∪ {0}.
- 每个查询带区域标签: R1 上命中点之后为 A. R2 上命中点之前为 B.

**每个时刻 t 的渲染内容**

| 图层 | 内容 |
|---|---|
| 背景 | 当前帧扫描点 (灰) |
| 真值 | box_t (实线框), box_0 (虚线框), t 时刻真实扫描点 |
| 预测 | 预测为 occupied 的查询点. 可选: 预测为 unknown 的查询点 (表示被该物体遮挡) |
| 标注 | 区域 B 的查询点用不同标记, 提示其是否在训练分布内 |

- 提供俯视图与透视图两种视角.
- 按 t 从 −3 s 到 +3 s 合成动画.

**指标**

| 指标 | 定义 | 对照 |
|---|---|---|
| 质心跟踪误差 | 预测 occupied 查询点的质心与 box_t 中心的距离, 随 t 变化的曲线 | B0: 当前物体点的质心 |
| 框命中率 | 预测 occupied 点中落在 box_t 内的比例, 并与落在 box_0 内的比例对比 | 若只是复制当前, 落在 box_0 内的比例高, 落在 box_t 内的比例低 |
| 观测一致性 | 有 G2 真值的位置上的三分类准确率 | B1 |

- 区域 A 与区域 B 分开统计.
- 若区域 B 不在训练分布内, 这部分只作展示, 不作结论.

## 8. 结果判读矩阵

| 观察到的现象 | 解释 |
|---|---|
| 任意 t 的预测与 t = 0 几乎相同 (B1 无差别) | 模型忽略了时间条件, 预训练未学到时序信息 |
| 不变束好, 变化束不优于 B0 | 只学到了当前几何 (重建项), 未学到运动 |
| 过去好, 未来差 | 主要在利用输入中的历史扫描, 预测能力弱 |
| 区域 A 好, 区域 B 差, 且训练未采样区域 B | 与训练覆盖一致, 不构成失败 |
| 事件类型判断正确, 但距离误差分布宽 | 时序判断有效, 深度定位受限 (见 3.5) |
| 运动点的 s_i 显著高于匹配静止点 (未来方向) | 学到了零样本运动线索 |
| 静止场景整体差, 自车运动场景好 | 怀疑静止场景的训练标签退化, 回到 5.7 核查 |
| 小物体 (≤ 19 点) 的 AUROC 显著低于大物体 | 运动线索对稀疏物体不足. 与下游 Recall_obj 的结论对照 |

## 10. 待确认事项

1. **预训练配置.**
   - 是否采样了命中点前方的重叠点? 这决定区域 B 是否在分布内.
   - unknown 样本是否设置了置信度下限? 这决定区域 D 的边界.
   - 实际使用的时刻集合 T 是什么?
2. **模型选择.** 使用哪个预训练模型 (训练轮次). 是否同时可视化多个轮次, 观察指标随训练的变化.
3. **B3 是否要做.** 它需要额外训练一个解码器.
4. **算力与运行环境.** 是否有显示设备 (决定是否提供交互式三维查看).
